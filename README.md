# M-quina-de-Turing
Repositório desenvolvido para a atividade de Teoria da Computação, abordando conceitos de Máquina de Turing, computabilidade e limites computacionais. Inclui a descrição teórica, a implementação de uma máquina no JFLAP para reconhecer palavras da forma 0ⁿ1ⁿ, testes de aceitação e rejeição e uma reflexão sobre problemas computáveis e indecidíveis.
